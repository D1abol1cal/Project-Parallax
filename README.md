# Project Parallax

A small single-page experiment with CSS/JS parallax scrolling — multiple layered background images that move at different speeds and scale as you scroll, built with plain HTML, CSS and vanilla JavaScript (no frameworks or build step).

## Running it

Just open `Index.html` in a browser, or serve the folder locally:

```bash
git clone https://github.com/D1abol1cal/Project-Parallax.git
cd Project-Parallax
npx serve .
```

Then scroll down the page to see the parallax effect.
